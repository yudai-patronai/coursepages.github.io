Заданная цифра в числе

Сколько раз цифра d входит в десятичную запись числа n?

Входные данные

Число 0≤d≤9. Пробел. Целое положительное число n в десятичной системе (0 ≤ n ≤ 3·10 6) .

Выходные данные

Сколько раз цифра d входит в запись числа n.

Примеры

Вход/Input

Выход/Output

2 123

1

3 1323533

4

English

How many times d is a digit in decimal representation of the number n?

Input format

Digit 0≤d≤9. Space. Integer decimal number 0 ≤ n ≤ 3·106

Выходные данные

How many times d is a digit in decimal representation of the number n.
