Один из способов шифровки сообщений состоит в том, что каждому символу исходного алфавита ставится в соотвествие символ нового алфавита. Напиши фукнцию кодирования строки из исходного в новый алфавит.

Напишите функцию, которая переводит строку src, записанную в алфавите alphabetA, в строку dst, записанную в алфавите alphabetB.

char * code (char * dst, char * src, char * alphabetA, char * alphabetB);

Функция возвращает адрес строки, записанной в новом алфавите. Исходная строка остается неизменной.

Символы не из алфавита переносятся в зашифрованную строку без изменения.

Функцию main реализовывать НЕ нужно. Проверку корректности аргументов не делать.
