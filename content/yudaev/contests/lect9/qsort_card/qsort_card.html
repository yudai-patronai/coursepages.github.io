Сортировка карт

Паша пишет курсовую по информатике - искусственный интеллект, который умеет играть в карты. Карты в колоде из 52 карт он хранит в виде структуры

struct Card {
    char suit;    // масть
    char rank;    // достоинство
};

Масти кодируются как 'c' (clubls - крести), 's' (spades - пики), 'h' (hearts - червы) и 'd' (diamond - бубны).
Достоинство кодируется как '2', '3', '4', '5', '6', '7', '8', '9', 'T' (ten - десять), 'J' (валет), 'Q' (дама), 'K' (король), 'A' (туз).

Помогите Паше, реализуйте функцию, которая сортирует массив card из n карт по возрастанию достоинства карты:
void card_sort(struct Card card[], int n);

Карты одного достоинства сортировать по мастям в следующем порядке: 'c' (clubls - крести), 's' (spades - пики), 'h' (hearts - червы) и 'd' (diamond - бубны).
