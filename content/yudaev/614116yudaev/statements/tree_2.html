Сортировка вставкой

Распечатайте последовательность натуральных чисел по возрастанию, печатая каждое число один раз. Для решения задачи используйте бинарное дерево. В строке вывода отразить с помощью скобок структуру дерева, как в примере. (Число пар скобок, внутри которых находится число равно глубине)

Входные данные

На вход программа получает последовательность натуральных чисел меньших 10000. Последовательность завершается числом 0, которое означает конец ввода, и печатать его не нужно.

Выходные данные

Числа по возрастанию со скобками. Без пробелов. Допустим лишний пробел в конце.
