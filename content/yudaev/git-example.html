On server:
mkdir my_project.git
cd my_project.git
git --bare init
On client:
mkdir my_project
cd my_project
touch .gitignore
git init
git add .
git commit -m "Initial commit"
git remote add origin username@url:/path/to/my_project.git
git push origin master
Когда репозиторий уже создан, и надо получить его копию в другом месте - используется
git clone username@url:path_to_git_dir

Для добавления новых файлов и папок:
git add new_files
git commit -m "....."
git push [origin master]
Для удаления:
git rm files
git commit -m "...."
git push [origin master]
