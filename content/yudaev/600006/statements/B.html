Паспорт Кощея

Ограничение по времени работы программы: 1 секунда.
Ограничение по памяти: 32 мегабайта.
Ввод из стандартного потока ввода (с клавиатуры).
Вывод в стандартный поток вывода (на экран).

Кощей Бессмертный родился в N-том году, а паспорт получил только в K-том году. Сколько лет Кощей Бессмертный прожил без паспорта?

Входные данные

N и K - два целых положительных числа, меньших 3000, по одному числу в строке.

Выходные данные

Количество лет, прожитых Кощеем без паспорта.

Примеры

Вход

Выход

1000

1970

970
