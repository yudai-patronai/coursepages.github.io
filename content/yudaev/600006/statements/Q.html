Дано множество X = {1, 2, ..., n} натуральных чисел от 1 до n. Найдите количество неупорядоченных наборов из k подмножеств множества X таких, что объединение любых двух из них размера не меньше n - 1.

Входные данные

Два целых числа 0 < n ≤ 8 и 0 ≤ k ≤ 2n

Выходные данные

Выведите одно число – ответ на задачу

Примеры тестов

стандартный вход стандартный выход
2 2 6

Примечание

Множества в первом примере: {{1,2},{}} {{1,2},{1}} {{1,2},{2}} {{1},{2}} {{1},{}} {{2},{}}
