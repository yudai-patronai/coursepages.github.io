Матрица

The matrix has you....

Time limit: 3 секунды

Memory limit: 1 гигабайт

Рассмотрим две квадратные матрицы А и В размера n. A[i][j]=НОД(i+1, j+1) B[i][j]=НОД(n-i+1, n-j+1), где НОД(x,y) - наибольший общий делитель чисел x и y (0 ≤ i < n, 0 ≤ j < n). Выведите количество элементов произведения матриц АВ, которые делятся на заданное число d.

Вход: целые числа n, d

Ограничения: 0 ≤ n ≤ 1024.

Ограничения: 1 ≤ d ≤ 100.

Пример

Ввод Вывод 
16 1
 
256
 
2 3
 
1
