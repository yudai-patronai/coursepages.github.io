вывод funny.out

Вася считает граф забавным, если модуль разности степеней любых двух вершин не превосходит 1. У него уже есть забавный граф, и он хочет получить из него удалением ребер забавный граф, в котором будет вершина степени d.

Входные данные

В первой строке входного файла заданы три целых числа N (1 ≤ N ≤ 300) — количество вершин графа, M (1 ≤ M ≤ N·(N - 1) / 2) — количество его рёбер и d (0 ≤ d ≤ 299) — требуемая степень вершины. Далее следуют M строк, каждая из которых содержит по 2 различных целых положительных числа, не превосходящих N — номера вершин, соединяемых соответствующим ребром. При этом любая пара чисел встречается не более одного раза.

Выходные данные

В случае, если Вася не сможет получить требуемый граф, выведите в первой строке "NO". Иначе выведите в первой строке "YES", во второй строке — количество рёбер в получившемся после удаления части рёбер графе, в третьей — номера оставшихся рёбер в возрастающем порядке (рёбра занумерованы в порядке их перечисления во входном файле, начиная с единицы). Если у задачи есть несколько решений, выведите любое.
