Мат.ожидание и дисперсия

Дана выборка значений (x1, x2, ..., xn) некоторой случайной величины X. Вычислить среднее значение m и среднеквадратичное отклонение d данной выборки, где d2 = ((x1 - m)2 + ... + (xn - m)2) / n.

Входные данные

На первой строке задаётся объём выборки - целое положительное число n, не большее 1000.

Следующая строка содержит n вещественных чисел - сами значения выборки.

Выходные данные

Два вещественных числа m и d через пробел.

Для вычислений использовать числа двойной точности.

Примеры

Вход

Выход

 
4
0 6 8 14
 
7 5
 
5
-7.5 3.2 -2 2.3 4
 
0 4.28439
