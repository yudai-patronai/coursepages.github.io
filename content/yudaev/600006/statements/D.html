Делители треугольного числа

Данные вводятся из текстового файла input.txt, выводятся в файл output.txt.

Последовательность треугольных чисел получается сложением натуральных чисел. Так, седьмое треугольное число - это 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28. Первые десять чисел этой последовательности:

1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...

Перечислим делители первых семи треугольных чисел:

1:

1

3:

1, 3

6:

1, 2, 3, 6

10:

1, 2, 5, 10

15:

1, 3, 5, 15

21:

1, 3, 7, 21

28:

1, 2, 4, 7, 14, 28

Видно, что число 28 - это первое треугольное число с более чем 5 делителями.

Чему равно наименьшее треугольное число с более чем N делителями?

Входные данные

Натуральное 1 ≤ N ≤ 500.

Выходные данные

Треугольное число, у которого более N делителей (неравенство строгое).

Примеры

input.txt

output.txt

5

28

2

6

The sequence of triangle numbers is generated by adding the positive integer numbers. So the 7th triangle number equals 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28. The first ten terms equals:

1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...

Let us list the factors of the first seven triangle numbers:

1:

1

3:

1, 3

6:

1, 2, 3, 6

10:

1, 2, 5, 10

15:

1, 3, 5, 15

21:

1, 3, 7, 21

28:

1, 2, 4, 7, 14, 28

We can see that 28 is the first triangle number to have over five divisors.

What is the value of the first triangle number to have over N divisors?

Input data

Positive integer 1 ≤ N ≤ 500.

Output data

Triangle number.
