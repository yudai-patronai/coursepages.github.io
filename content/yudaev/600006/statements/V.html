Саша живет в общежитии. У него много вещей, большинство из которых, честно говоря, бесполезны. Перед отъездом на летние каникулы он столкнулся с проблемой упаковки вещей. У Саши B ящиков, T типов вещей, N вещей этих типов и Q операций с ними. Помогите ему выполнить все операции. Существует два типа операций:

  1. Узнать сколько вещей t типа в k ящике.
  2. Достать все вещи типа t среди верхних n вещей k-ом ящике и положить их наверх m-ом ящике.

Входные данные

Первая строка содержит два целых числа: N (1 ≤ N ≤ 105), T (1 ≤ T ≤ 105). Следующая строка содержит целое число B (1 ≤ A ≤ 105). Каждая из следующих B строк описывает один ящик. Она начинается с целого числа n (0 ≤ n ≤ 105) - количество вещей в этом окне. Далее n целых чисел, которые описывают типы вещей в ящике (от нижних к верхним). Гарантируется, что общее число вещей во всех ящика равно N. Следующая строка содержит целое число Q (1 ≤ Q ≤ 105). Каждая из следующих Q строк содержит описание операции. Первое число z - тип операции. Если z = 1, то эта строка содержит два целых числа: t (1 ≤ t ≤ T), k (1 ≤ k ≤ B). Если z = 2, то эта строка содержит четыре целых числа: t (1 ≤ t ≤ T), k (1 ≤ k ≤ B), n (0 ≤ n ≤ 105), m (1 ≤ m ≤ B, m ≠ k). Гарантируется, что количество вещей в k-ом ящике не меньше, чем n.

Выходные данные

Выведите для каждой операции первого типа искомое количество вещей. Числа следует отделять друг от друга переводом строки.
