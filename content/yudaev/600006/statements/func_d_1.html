Периметр треугольника

Даны координаты вершин треугольника A(x1, y1), B(x2, y2), C(x3, y3). Написать функцию:

double perimeter(double x1, double y1, double x2, double y2, double x3, double y3);

вычисляющую периметр треугольника.

Входные данные

Параметры функции - шесть вещественных чисел x1, y1, x2, y2, x3, y3, являющиеся координатами вершин треугольника, в указанном порядке.

Выходные данные

Возвращаемое значение функции - вещественное число - периметр треугольника.

Для вычислений использовать числа двойной точности.

Функцию main реализовывать НЕ нужно.
