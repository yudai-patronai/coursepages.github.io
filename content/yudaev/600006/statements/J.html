Задача принимается только на С

2033 год. Библиотекари шли по туннелю метро и встретили Артёма. "Вот тебе и раз", - подумали библиотекари. "Вот тебе и два, наверное, один 32-, другой 64-битный", - подумал Артём. - "Надо спросить у них, какие динамические библиотеки у них есть".

Помогите Артёму написать программу, которая примет на вход название динамической библиотеки, а затем с помощью dlopen попытается выяснить, есть ли такая в системе. Денег у библиотекарей нет, так что они используют только ПО с открытым исходным кодом.

Примечание: задача тестируется под Linux
