Генератор Случайных Строк (ГСС) выдает строчку состоящую из латинских букв 'A' и 'B'. У генератора есть параметр k – длина суффикса генерации (ниже объяснено что это). Для каждого тесткэйса k выбирается случайно и равновероятно из множества {1, ..., 10}. Процесс генерации устроен так: первые k символов строки выбираются независимо, каждый из них равен 'A' с вероятностью 1 / 2. Каждый следующий символ выбирается в зависимости от k предыдущих. Если если последние k букв слова образуют суффикс s, то с вероятностью psA следующей буквой будет буква 'A', и с вероятностью psB = 1 - psA будет буква 'B'. Все значения psA для разных суффиксов выбираются перед началом генерации (но после выбора k) независимо и равномерно на отрезке [0, 1] (это значит, что вероятность psA < t равна t для любого ). Вам дана строка w, сгенерированная ГСС. Вам нужно найти вероятность того, что следующим символом в строке будет буква 'A'. Гарантируется, что вероятность генерации строки w во входе больше нуля (иными словами, что данные корректны)

Входные данные

В первой строке находится число T – количество тестов, 1 ≤ T ≤ 10000. Следующие T строк описывают тесты. В каждой их них находится не пустая строка, состоящая только из символов 'A' и 'B'. Все тесты сгенерированы независимо (и могут иметь разные параметры). Сумма длин строчек во всех тестах не превосходит 10000.

Выходные данные

Для каждого теста вы должны вывести одну строку с требуемой вероятностью, посчитанной с точностью 10 - 6.
